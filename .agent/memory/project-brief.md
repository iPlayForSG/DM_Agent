# 项目简报

## 解决的问题

DM_Agent 为单人 D&D 2024 跑团提供本地优先的数字主持人：模型负责理解自然语言、规划和中文叙事，确定性规则层负责可验证的角色、战斗、资源和存档变化。

## 主要用户与场景

- 主要用户：希望独自进行中文 D&D 2024 冒险的玩家。
- 主要场景：创建 1 级角色、选择或生成冒险、通过自然语言探索/交谈/行动、进行遭遇和战斗、查看状态、删除或重写历史消息。
- 开发场景：本机 Windows 一键启动；OpenAI-compatible 模型服务可配置；规则检索可完全本地运行。

## 核心业务域

- 角色构筑与角色卡派生值。
- 冒险章节、线索、搜索和持久战役记忆。
- 对话、探索、检定、法术、物品和特性。
- 遭遇、先攻、行动经济、伤害、倒地与集中。
- 回合审计、失败回滚、暂停/恢复和消息分支。
- D&D 2024 规则目录与可选 RAG 检索。

## 范围边界

- 当前是本地 JSON 持久化的单机应用，不是多租户服务。
- 前端不是规则事实源；不在浏览器复制战斗结算。
- RAG 只提供规则上下文，不能直接修改游戏状态。
- 行动建议是非事务 UI 投影，不是合法行动的完整枚举。
- 标准怪物库是只读内容资产；游戏内模型生成怪物属于存档状态。
