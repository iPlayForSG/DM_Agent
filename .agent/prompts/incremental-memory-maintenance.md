# 增量项目记忆维护

你正在由项目 `Stop` hook 继续的“只维护记忆”回合中。

1. 不再修改产品代码、测试或产品配置。
2. 读取根 `AGENTS.md`，再只读取触发证据相关的 memory、当前 active ExecPlan、代码和配置；不要一次加载全部 `.agent/memory/`。
3. 以当前代码、测试、配置和 `Accepted` ADR 为事实源。若 memory 冲突，核对代码后修正 memory。
4. 判断本次变化是否形成未来任务仍长期有效的新事实。
5. 最小化更新：优先当前 ExecPlan，其次相关 memory；只有重大长期技术决策才新增 ADR；只有稳定入口或全局工程规则变化才改 `AGENTS.md`。
6. 若没有长期知识变化，不修改文档，并在最终说明“无需更新长期记忆”。Hook 仍会把本指纹标为已审计。
7. 不记录聊天流水账、提交摘要、短期实现细节、完整 diff、完整 transcript、日志或敏感信息。
8. 检查修改后的路径、命令和 Markdown 链接，运行 `git diff --check`。
9. 最终只汇报是否更新、更新了什么，或为何无需更新。

Hook 会在本提示之后附上有限的变化类别、文件、模块和建议检查文档。不要扩大到无关范围。
