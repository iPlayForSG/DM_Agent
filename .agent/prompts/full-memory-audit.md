# 全量项目记忆校准

这是人工触发、Automation、版本发布或大型合并后的完整校准任务，只允许修改项目文档、`.agent/`、ADR 和必要的项目级 Codex 配置；不得修改产品代码。

1. 读取 `AGENTS.md`、所有 memory 索引与当前 active ExecPlan。
2. 以代码、测试、配置和 `Accepted` ADR 为事实源，定向核对：
   - 失效路径和错误命令；
   - 架构描述与实现冲突；
   - 模块职责或公共接口漂移；
   - 重复、矛盾或已失效约束；
   - 缺失的重要模块说明；
   - 本应进入 ADR 的重大长期决策；
   - 过度详细、污染上下文的低价值内容。
3. 对忽略但本机存在的设计文档，只作只读参考；若与代码冲突记录并修正可跟踪 memory。
4. 删除或压缩低价值重复内容，保留清晰链接，不复制大段源文档。
5. 不记录密钥、本地游戏内容、完整 transcript、完整 diff 或提交流水账。
6. 复核 `commands.md` 的依据；未执行命令不得标记成功。
7. 检查 Markdown 相对链接、JSON 合法性和 hook 脚本路径。
8. 运行 hook tests 与 `git diff --check`，最终列出修改、冲突、验证和待确认项。
