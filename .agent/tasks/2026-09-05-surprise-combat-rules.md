# 2024 躲藏与突袭进战规则实现

Status: active
Updated: 2026-09-05

## Goal

实现躲藏动作、察觉发现、躲藏失效、2024 突袭/隐形先攻修正及不可见攻击者修正，并将自然语言突袭意图接入确定性工具流程。

## Scope / Non-goals

- 改 schema、规则层、工具注册/阶段能力、API 与必要的 UI 状态展示；保存兼容和失败回滚必须保留。
- 以本地玩家手册2024与已完成的突袭审计为依据，不实现旧版突袭轮或凭空授予 Sneak Attack 职业伤害。
- 没有网格视线模型：遮蔽/掩护、是否已被看见、是否未察觉开战仍是 DM 的明确场景裁定；成功检定和数值修正必须由工具产生。
- 使用独立工作副本与合成存档，避免热重载中断玩家回合。

## Decisions

- 躲藏产生独立来源状态，不通过删除通用 Invisible 标签清除魔法隐形。
- Surprise 记录为遭遇开场事实，只影响先攻；不跳过首回合，已开始的战斗不能重设突袭。
- 无有效掩护或正被敌人看见时拒绝躲藏且不掷骰；合法尝试检定失败仍是已执行动作。
- 非躲藏造成的意外开战可通过明确的 other 来源和场景理由裁定，不强制额外的通用“突袭检定”；不能用该路径把失败躲藏改成成功。
