# 暂停回合的本地写入保护（F12）

Status: completed
Updated: 2026-09-05

## Goal

用户在理解 interrupt 继续与历史 rewind 的区别后，授权修复 F12：暂停期间拒绝冲突的本地写入，避免继续剧情时覆盖已保存状态。

## User-visible outcome

剧情选择待处理时显示原因并禁用本地动作/设置；完成、取消或明确回退后恢复操作。旧暂停存档若已发生业务变化，保留当前公开状态并安全结束失效暂停。

## Scope / Non-goals

- In scope：API 写入口、存储防线、旧 checkpoint 基线一致性、前端禁用状态与回归测试。
- Non-goal：读取或直接改写玩家存档、改动明确剧情回退的资源恢复语义、全局模型配置权限、提交。

## Discoveries / surprises

- GET 游戏在冒险选择阶段可能补写选项，暂停时也应保持只读。
- 比较暂停基线时需忽略存储版本、时间戳、暂停元数据、trace 与消息建议缓存，不能把合法投影当成业务漂移。
