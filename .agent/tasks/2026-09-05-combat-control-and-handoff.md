# 战斗控制权与玩家决策点

Status: completed
Updated: 2026-09-05

## Goal

修复动作耗尽时的重复攻击和过程说明污染失败回复；队友默认 DM 控制、支持切换，战斗持续结算至下一玩家决策点，允许简短战斗叙事并使用独立卡片颜色。

## Scope / Non-goals

- 主控角色保持玩家控制，游戏内其他角色默认 DM 控制，控制偏好仅属于该局，不改角色模板。
- 敌人及 DM 队友必须经过真实工具和掷骰；抵达玩家控制角色后不得复用上一条指令自动替其行动。
- 没有可行动玩家但仍有存活队友时，停下说明并允许切换控制，避免自动推进无止境战斗。
- 保留当前 main 中既有的 defensive-code-cleanup 未提交修改，不将其回退或擅自发布。
- 使用独立工作副本和合成存档，不读取真实玩家会话或强制重启活动后端。

## Decisions

- 新角色控制默认为“主控玩家、其他 DM”，明确切换结果写在 GameState 中。
- 对话中的公开过程说明不能作为最终回复；失败必须给出失败原因，不允许剩余动作不足时反复要求攻击。

## Discoveries

- 交还玩家决定权前不再允许额外动作，因此不能依赖后续模型的 set_active_character 修复选择；先攻进入队员回合时必须由确定性规则同步活动角色引用，主控身份保持稳定。

- 旧测试的攻击/躲藏结尾需要增加正常回合交接；暂停基线比较需要将新增主控身份规范化。
