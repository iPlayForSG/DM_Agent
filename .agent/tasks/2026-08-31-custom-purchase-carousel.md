# 自定义购买分类轮播

Status: completed
Updated: 2026-09-05

## Goal

将角色构筑器“自定义购买”中的装备分类卡片改为卡片内分页轮播，每页最多展示 3 项，避免分类卡片被完整商品列表纵向撑大。

## Design read

- 页面类型：高密度角色构筑表单中的目录选择组件。
- 用户：需要快速比较价格并增减装备数量的玩家。
- 功能契约：3 秒内看清分类、当前范围与数量控件；每页最多 3 项；翻页不丢失购买数量；键盘和窄屏可用。
- 拨盘：视觉冒险度 4 / 动效强度 4 / 信息密度 7。
- 模式：已有方向 D“冒险面板”，本次走打磨模式。

## Component dossier

- 选型：分类卡片内分页列表；不用横向拖拽轮播，因为商品行包含数量步进器，拖拽会和点击、移动端纵向滚动产生手势冲突。
- Anatomy：分类标题、当前范围、上一页、下一页、最多 3 条商品行、数量步进器。
- Content：优先显示本地化商品名、价格、包装数量、伤害/护甲与分类。
- States：默认、已购买、上一页/下一页禁用、数量为 0 时减少按钮禁用、空列表不渲染分类。
- Keyboard：所有动作使用原生 button；Tab 可达；Enter/Space 触发；焦点环可见。
- Narrow viewport：分类网格塌缩单列，仍保持每页最多 3 项。
- Overflow：商品文本容器 `min-width: 0` 并允许自然换行；不产生横向滚动。
- Recovery：翻页仅改变可见窗口，不修改购买状态；页码越界时派生到最后一个有效页。

## DNA injection

采用 Notion 设计系统中的 3 个具体动作，并服从本项目色板：

1. `1px` 轻描边组织层级，不使用左侧色条。
2. 标准卡片 `12px` 圆角。
3. 以 `8px` 为基础的紧凑间距节奏，并用极轻多层阴影表达已选状态。

## Decisions

- 每页固定 3 项，不在窄屏降低为 1–2 项；商品采用纵向紧凑行，符合用户“只展示前三项”的原意并稳定卡片高度。
- 分页状态按分类组件实例独立保存，不写入 URL；它是构筑步骤内的临时浏览位置，不具备分享或重载价值。

## Validation

- 浏览器桌面视口：每张分类卡片最多 3 项；单页分类不显示无效翻页按钮。
- 浏览器真实交互：链甲衫加购至 1，翻到护甲第 2 页再返回，数量仍为 1。
- 浏览器 390px 窄屏：分类单列、每页 3 项、页面 `scrollWidth === clientWidth === 375`，无横向溢出。

## Craft loop review

- 艺术总监：单页分类的两枚禁用箭头造成无意义 chrome；第二轮改为只显示“共 N 项”。
- 工程师：长商品名让商品行高参差；第二轮统一最小行高，并补 `focus-within` 状态。
- 甲方：范围提示过弱，三秒定位页码不够稳；第二轮提高数字提示字重和对比度。
