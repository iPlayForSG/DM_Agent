# 项目级 AI 记忆

此目录保存可随仓库演进的高信号项目上下文，不依赖聊天历史、RAG、MCP、向量数据库或外部记忆服务。

## 结构

- `memory/`：按主题拆分的长期事实，按需读取。
- `tasks/`：跨会话 living ExecPlan。
- `prompts/`：Hook 自动维护和人工全量校准提示。
- `PLANS.md`：ExecPlan 规范。

`AGENTS.md` 是稳定入口；本目录不是第二套百科。代码、测试、配置和已接受 ADR 发生冲突时优先，并修正这里的过期信息。

## 维护原则

- 只记录未来任务仍会反复用到的事实、边界、命令和坑点。
- 链接权威文档，避免复制长篇设计说明。
- 推测必须标为“待确认”。
- 不保存密钥、完整 transcript、本地游戏内容或提交流水账。
- 任务完成时只做最小增量更新；需要系统校准时使用 `prompts/full-memory-audit.md`。
