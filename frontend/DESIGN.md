# DM_Agent 前端设计锚 · 方向 D「冒险面板」

> 唯一事实源。改风格先改本文件。2026-08-30 经四方向预览（A 烛下账本 /
> B 战术桌面 / C 篝火说书 / D 冒险面板）用户选定 D。

## 1. 视觉主题与氛围
现代跑团平台：亮色、温暖、干净、卡片化。像 D&D Beyond 与 Notion 的混合体，
而不是暗色管理后台。玩家的情绪目标："我在一个精心打理的冒险平台上跑团"。
拨盘：视觉冒险度 4 / 动效强度 4 / 信息密度 6（功能页区间）。

## 2. 色板与角色
- 底色：`#f7f5f1`（暖米白，全应用背景）
- 表面：`#ffffff`（卡片、输入框、侧栏）
- 描边：`#e8e2d5`（卡片）、`#e4ddd0`（分隔线）
- 墨色：`#26221c`（主文字）、`#6d6a5f`（次要文字）、`#a89f8d`（占位）
- 主色（行动/品牌）：`#9f3d34`（赤陶红，按钮、玩家气泡、HP 条）
- 辅色（队伍/成功）：`#4b806a`（鼠尾草绿，标签、成功态、牧师类资源）
- 强调（黄铜）：`#b8a16a` 仅用于"DM 叙事"身份标识，如卡片顶边
- 功能色语义固定：绿=成功 橙=警告 红=错误/HP 蓝=信息
- 数字一律 `font-variant-numeric: tabular-nums`

## 3. 排版规则
- 正文/UI：`"Segoe UI Variable", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 展示（标题/章节）：`Georgia, "Songti SC", "SimSun", serif`，仅限页面级标题与冒险名
- 行高 1.6-1.7；中文正文 ≥ 14px（密集表格可 12px）；中西文之间加空格
- 默认禁用斜体；唯一语义例外是叙事内的公开普通骰点，使用斜体 + 信息色双重区分。其余层级靠字重与颜色，不靠无脑放大

## 4. 组件样式
- 卡片：白底、`border: 1px solid #e8e2d5`、`border-radius: 12px`、
  `box-shadow: 0 1px 2px rgba(38,34,28,.05)`；只有需要 z 轴层级时用卡片
- DM 叙事卡：`border-top: 3px solid #b8a16a`；玩家气泡：绿底白字圆角 12px
- 按钮：主=赤陶红底白字、`border-radius: 999px`；次=白底描边；危险=红描边
- 徽标/状态：pill（`border-radius: 99px`），11-12px，600 字重
- HP 条：5px 圆角胶囊，红 `#9f3d34`，绿仅用于治疗/满血语境
- 输入框：白底、`#e8e2d5` 描边、focus 环 `#9f3d34` 40% 透明
- 叙事内公开骰点：以 `骰点｜` 开头，靛青绿 `#2f6f76`、500 字重、斜体；攻击结算以 `战斗｜` 开头，赤陶红 `#8d342e`、600 字重。两者紧跟对应动作句段，不单独堆到回复开头
- 自定义购买分类：每张分类卡片内部按 3 项一页分页；页头提供范围提示与前后翻页按钮，
  商品数量在翻页后保持。窄屏仍维持 3 项上限并塌缩为单列，避免横向拖拽与数量步进器争抢手势。

## 5. 布局原则
- 会话页 = 对话流（主）+ 右侧角色/战斗面板（辅，176-220px）
- 会话按发生顺序呈现：暂停快照必须先补回 `pending_turn.original_input` 对应的玩家原始发言，
  待玩家处理的选择或确认再紧跟其后；不得固定在聊天区顶部或脱离上下文。
- 玩家发送普通发言或选择后，玩家气泡必须立即乐观插入消息流并滚动到可见位置；服务端快照返回后
  用权威聊天记录对账且不重复。失败时保留失败态、恢复输入内容，明确允许重试。
- 主持回合执行期间，在对话流中实时展示可公开的 Agent 文本与阶段进度；内容使用 Markdown 引用语义，
  运行时保持展开，结束后自动折叠，并提供带 `aria-expanded` 的小尖角按钮重新展开。该区域是观察性进度，
  不代表隐藏推理，也不改变服务端最终回合结果的权威性。
- 运行过程优先显示公开处理说明与当前模型响应次数、等待秒数，不堆叠内部节点完成清单；服务端接收行动后标记“主持处理中”，避免持续误报“发送中”。
- 列表优先 divide-y 与留白，不滥用卡片
- 队伍物品栏可独立折叠，默认展开；人物卡以“剩余 / 基础额度”显示动作、附赠动作和反应，非当前行动者不显示其他人的动作余量。场上列表遵循服务端先攻顺序并显示序号，用边框突出当前行动起点。
- 队伍中的法术与有说明的物品名称用细虚线提示可查看详情；悬停、键盘聚焦或点击显示阅读浮层，允许移入滚动，Escape 关闭。无说明时保留普通文本；浮层不被侧栏裁切且保持在视口内。
- 组内间距 < 组间间距；容器内容宽度上限 1280px
- 侧栏导航：白底、右侧 1px 描边、选中项浅米色圆角块 + 赤陶红文字

## 6. 深度层级
- z0 背景 `#f7f5f1` → z1 白卡片 → z2 侧栏抽屉 → z3 弹窗 → z4 toast
- 阴影只用两级：卡片 `0 1px 2px`；浮层 `0 8px 24px rgba(38,34,28,.12)`

## 7. Do's
- 骰子结果/建议行动用浅绿或浅米底色卡片突出，给玩家"高光时刻"
- 空态要美观且指导下一步
- 每个可交互元素 hover/active/focus-visible/disabled 全实现

## 8. Don'ts
- 不回归暗色；不用紫蓝渐变、玻璃拟态、外发光、斜体
- 不用编号式 meta-label（"SECTION 01"）
- 中文界面不用装饰 webfont

## 9. 响应式行为
- <768px：会话侧栏塌缩为底部可展开区；非对称布局塌缩单列
- 禁 `h-screen`，用 `min-height: 100dvh`；flex 文本子项加 `min-width: 0`
- 根容器宽度用 `100%`，不用 `100vw`；后者会在移动端竖向滚动条出现时制造横向溢出

## 10. Motion 哲学
- 反馈动效 100-160ms、ease-out（`cubic-bezier(.23,1,.32,1)`）；浮层 200-300ms
- 只动 `transform/opacity`；`prefers-reduced-motion` 兜底；高频键盘操作不加动画
