# DM_Agent 前端设计锚 · 曜金羊皮编年史（Illuminated Tabletop Chronicle）

> 唯一事实源。改风格先改本文件。在方向 D「亮色冒险面板」的基础上深化为兼具典藏跑团手册质感与现代编辑台效率的「曜金羊皮编年史」设计体系。

## 1. 视觉主题与氛围
现代单人跑团编年史与战术桌面：温暖羊皮纸底色、象牙白卡片表面、古黄铜细线纹章、赤陶朱红行动标识与鼠尾草青绿成功/队伍语义。
像《D&D 2024 典藏版角色卷宗》与 Readwise / Notion 编辑美学的结合体，彻底告别暗色运维后台与廉价模板感。
玩家的情绪目标："我正坐在一张精心打理、灯光温暖的跑团桌前，翻阅一部实时书写、规则严明的冒险编年史"。
拨盘：视觉精致度 8 / 动效克制感 5 / 信息密度 7（桌面跑团工作台区间）。

## 2. 色板与语义 Token
- 画布底色：`--bg-canvas: #f4efe6`（暖羊皮米色）、`--bg-canvas-alt: #ebe4d6`（深一层羊皮底）
- 纸张表面：`--surface-card: #fffdf9`（象牙白主卡面）、`--surface-soft: #f8f4ec`（次级内嵌块）、`--surface-warm: #f1eadc`（暖色高亮区）
- 描边与分隔：`--border-card: #e3dac8`（主卡描边）、`--border-soft: rgba(44, 36, 26, 0.09)`（内部细分割线）、`--border-brass: rgba(176, 141, 78, 0.48)`（黄铜强调线）
- 墨色层级：`--ink-strong: #1f1b16`（标题浓墨）、`--ink-body: #2d2720`（正文墨色）、`--ink-muted: #6e675b`（辅助说明）、`--ink-faint: #9e9585`（占位与次要序号）
- 核心品牌与行动色：
  - 赤陶朱红（主行动 / 生命 / 战斗）：`--accent-crimson: #9b382e`、悬停 `#822d24`、浅底 `#fdf1ee`
  - 鼠尾草青（队伍 / 玩家宣言 / 增益 / 成功）：`--accent-sage: #3d725c`、深色 `#2e5947`、浅底 `#eef6f2`
  - 古黄铜金（DM 叙事身份 / 典藏边框 / 徽记）：`--accent-brass: #b08d4e`、深色 `#846631`、浅底 `#fbf6ec`
  - 秘法靛蓝（专注 / 规则信息 / 明骰标识）：`--accent-indigo: #396273`、浅底 `#eef5f8`
  - 警示与危险：`--accent-warning: #b57624`、`--accent-danger: #c0392b`
- 数字排版：所有属性、HP、骰式、金币、先攻与轮次一律 `font-variant-numeric: tabular-nums`。

## 3. 排版与图标规则
- 展示与标题字体（Display）：`"Palatino Linotype", "Book Antiqua", Georgia, "Songti SC", "Noto Serif SC", "SimSun", serif`，用于页面主标题、角色姓名、战役标题、DM 章节叙事首字与属性大数字。
- 正文与界面字体（Body）：`"Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", "Noto Sans SC", sans-serif`，行高 1.65–1.75，中文正文 ≥ 14px。
- 规则与数值字体（Mono/Utility）：`"Cascadia Mono", "JetBrains Mono", "Consolas", monospace`，用于骰点公式、法术位、坐标与回合计数。
- 默认禁用斜体；唯一语义例外是叙事内的公开普通骰点（`骰点｜…`），使用斜体 + 靛青底色徽章双重区分。
- 图标系统：使用定制线性/纹章 SVG 跑团图标（二十面骰 d20、羽笔卷轴、盾牌、双剑、星芒法书、指南针等），替代原先简陋的单汉字方框。

## 4. 核心组件范式
- **典藏卡片**：象牙白底 `#fffdf9`、`1px solid #e3dac8`、`border-radius: 12px`、柔和纸张投影 `0 2px 6px rgba(38, 30, 20, 0.04)`。
- **DM 叙事卷宗卡**：顶部 `3px solid var(--accent-brass)` 镶边，左上方带精巧的叙事身份角标；战斗叙事消息（`narrative_mode === "combat"`）采用赤陶暖底与棕红顶边，类型随消息持久化保存，遭遇结束后不重染历史卡片；规则调整提示（`narrative_mode === "rules_feedback"`）带琥珀金左侧边与「行动需要调整」题头。
- **玩家行动宣言卡**：右对齐，深鼠尾草青底白字配微光细边，悬停或聚焦时浮现「修改并重写 / 删除」操作工具条。
- **本轮骰点账本（RollLedger）**：位于 DM 回复上方的紧凑折叠骰盘条，展示总掷骰次数与暗骰统计；展开后以等宽算式胶囊、明/暗骰标签、优劣势、目标值与重击/结算状态清晰陈列。
- **叙事内语义高亮**：
  - 公开普通骰点（`骰点｜` 开头）：靛青色 `#285e68`、500 字重、斜体与淡青底衬。
  - 攻击结算（`战斗｜` 开头）：赤陶红 `#8d342e`、600 字重与淡红底衬。
  - 物品增减（`物品｜` 开头）：翠青色 `#266b58`、左侧 3px 竖线与浅绿底衬，明确写出物品名、变化量与现有数量。
- **自定义购买分类轮播（ShopCarousel）**：每张分类卡片内部按 3 项一页分页，页头提供范围提示与前后翻页按钮，翻页后保留已选商品数量；窄屏塌缩为单列。
- **全局单窗说明浮层（DescriptionTooltip）**：法术、职业资源、状态与有说明的物品名称用黄铜细虚线底边提示；悬停 1.5 秒固定（带光标进度环）、键盘回车固定、Escape 或叉号关闭，通过 Portal 挂载到 `document.body` 防止裁切。

## 5. 页面布局与交互原则
- **大厅主页**：
  - 顶部双栏英雄席：左侧跑团主持台宣言与当前存档/角色概览，右侧三张不对称纹章入口卡（新建游戏、创建角色卡、角色卡模板）。
  - 模型引擎状态横幅：默认展示精炼的当前模型档案、接入方式、连接健康状态灯与快速切换下拉框；点击「配置档案 / 新建档案」平滑展开完整参数表单（当模型连接未就绪时自动展开提醒）。
  - 双栏典藏列表：已保存游戏（带场景徽标、战斗中脉冲标签、单局与批量删除）与角色卡模板（带职业、等级、单张与批量删除）。
- **跑团会话主桌**：
  - **顶部会话指挥栏**：整合跑团标识、当前存档标题、场景阶段胶囊、回合计数、模型状态指示、「叙事主桌 / 战役编年史」视图切换以及「返回主页」按钮，释放原先左侧 248px 空旷导航栏占用的水平空间。
  - **主叙事对话流 + 底部行动输入坞**：
    - 按发生顺序呈现：暂停快照先补回 `pending_turn.original_input` 对应的玩家原始发言，待玩家处理的选择卡紧随其后。
    - 玩家发送后立即乐观插入消息流并滚动可见，状态随 `turn.started` 切换为「主持处理中…」，失败时恢复输入并支持重试。
    - 主持思考面板（DmThinkingPanel）实时流式展示公开过程文本与等待秒数，运行中展开、完成后自动折叠；中断原因常驻展示。
    - 底部输入坞集成自由文本输入、快捷键提示、重写状态横幅，以及收纳于输入坞工具栏内的「主持文本篇幅」设置浮层/折叠区。
  - **右侧会话辅助栏（380–460px）**：
    - 顶部提供「队伍与战局」和「线索与日志」分段切换标签，让玩家无需离开聊天即可随时查阅队伍角色卡、场上先攻形势、线索证据、战役见闻与近期时间线。
    - 队伍角色卡展示生命条、3 列核心防御属性（护甲/速度/先攻）、6 维属性与调整值、状态栏（增益绿/减益红/专注蓝，版本未同步时显示「状态待同步」）、行动额度（动作/附赠动作/反应，仅当前行动者显示剩余量）、职业资源、法术、攻击、熟练与可折叠物品栏（直接展示伤害/治疗/卷轴环级与分行效果摘要）。
    - 队友卡片摘要旁提供不触发卡片折叠的「玩家控制 / DM 控制」切换按钮。
    - 场上形势按先攻顺序排列并高亮当前行动者。
- **角色构筑向导（1–20 级）**：
  - 顶部五步进度轨 + 实时角色摘要条（实时反映已选等级、种族、背景、职业、生命上限、剩余购点/预算）。
  - 完整支持 1–20 级建卡、三种属性生成方式（27 点购点、标准数组、4d6 去最低骰池分配）、子职业与升级属性提升、标准套装/自定义商店购买、戏法/准备法术/额外法术/玄奥秘法选择与总览校验。

## 6. 深度层级与动效
- 层级：z0 羊皮画布 `#f4efe6` → z1 象牙白卡片 `#fffdf9` → z2 粘性顶栏与侧栏 → z3 模态框 (`z-index: 100`) → z4 全局说明浮层 (`z-index: 1000`)。
- 动效：交互反馈 120–180ms `cubic-bezier(0.22, 1, 0.36, 1)`；浮层与卡片入场 200–260ms；严格支持 `prefers-reduced-motion: reduce`。

## 7. 响应式与红线约束
- `<1024px`：会话主桌与右侧辅助栏塌缩为上下或抽屉式单列布局；角色册左右分栏塌缩为单列。
- `<768px`：所有多列网格安全塌缩；根容器使用 `width: 100%` 与 `min-height: 100dvh`，所有 flex/grid 文本子项带 `min-width: 0` 防止横向溢出。
- 红线：不回归暗色；不生成自动行动回复建议；不在浏览器复制后端规则计算；所有异步响应严格遵守 `gameLifecycleRef`、`gameSyncRequestRef` 与 `state_version` 守卫。
